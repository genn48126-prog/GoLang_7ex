# Микросервисное приложение для учета финансов

Проект состоит из двух микросервисов:
1. Gateway — шлюз, который принимает HTTP-запросы и проксирует их в Ledger.
2. Ledger — основной сервис, который содержит бизнес-логику, хранит данные в PostgreSQL и кэширует отчеты в Redis.

## Архитектура и хранилища
* PostgreSQL — основное хранилище для бюджетов и транзакций.
* Redis
* Goose

## Предварительные требования
* Установленный [Go](https://go.dev/) 
* Установленный [Docker](https://www.docker.com/) и Docker Compose
* Установленная утилита [Goose](https://github.com/pressly/goose)
